# 债券研究报告前置板块撰写技能

本技能依据报告正文，一次性生成三个前置板块：**摘要**、**报告亮点**、**投资逻辑**。

---

## 一、读取正文

用户提供正文的方式可能有以下几种：

1. **直接粘贴正文文字**：直接使用上下文中的内容进行分析。
2. **上传文档文件（.docx/.pdf）**：使用 `extract-text` 或 `bash_tool` 读取，**跳过**目录、图表目录、免责声明、封底、团队介绍、机构销售通讯录等非正文内容，聚焦正文主体。
3. **仅提供结构信息**：先向用户确认是否能补充更多正文，若无法补充则基于已有内容尽力撰写。

---

## 二、正文解析：识别三个关键属性

动笔之前，先回答以下三个问题。**答案决定三个板块的写法**，不要跳过。

### 问题一：报告的时间视角是什么？

- **前瞻型**：报告有明确的后市判断和操作建议（"策略""操作建议""下周关注"等）。包括各类周报、月报、策略报告、信用策略。→ 投资逻辑写"判断依据 + 操作建议"。
- **回顾型**：报告以复盘、回顾为主，无前瞻性操作建议（"复盘""回顾""阶段分析"等）。包括季度复盘、年度复盘、阶段性行情回顾。→ 投资逻辑写"驱动因素梳理 + 规律总结"。

### 问题二：报告是否包含独立的"专题/方法论"模块？

- **有专题分析模块**：报告设有独立章节，深度分析某个特定领域或问题（如"地产债利差分析""久期测算方法""城投再融资研究"）。→ 摘要和报告亮点需重点覆盖该专题。
- **有方法论创新模块**：报告提出新的量化方法、指标体系或分析框架，有理论基础和验证过程。→ 报告亮点侧重理论创新，投资逻辑侧重"问题→解决方案"逻辑链。
- **无专题/方法论**：报告为综合性市场分析，无独立专题章节。→ 报告亮点侧重本期最具价值的市场洞察。

### 问题三：报告是否包含"标准跟踪数据"章节？

标准跟踪数据章节是指信用周报、利率周报等定期报告中固定出现的数据汇总板块，如：二级市场收益率变动一览、一级市场发行/偿还/净融资、成交流动性、评级调整、各品种利差宽窄分布等。

- **有**：这些章节在**摘要中全部跳过**，不作概括。这些章节是数据支撑，核心判断在专题和策略章节中。
- **无**：报告所有章节均需按顺序概括。

## 三、摘要撰写规范

**功能**：全文结构性提炼，让读者不看正文也能掌握报告核心内容。

**共通格式要求**：
- 严格按报告一级章节的逻辑顺序展开，每节对应一个段落（跳过标准跟踪数据章节）。
- 每段以**加粗的章节主题词**开头，措辞参照正文标题，后接核心内容。
- 数据优先：能引用具体数字（BP、收益率点位、规模、时间段）的地方不用"明显""较多"代替。
- 最后单独一段：**风险提示：**[原文]。
- 总字数：**300～700字**，按章节数弹性调整。

**根据正文结构，选择对应的摘要写法：**

---

### 写法1：章节顺序型（最常见）
适用于：利率周报、月报、策略报告等——报告章节本身是最优的概括框架。

逐章概括，每章1段，按"结论先行 → 支撑逻辑/数据"展开。对于策略章节，保留品种、期限、利差数值等具体操作信息。

```
[行情总括句，含关键收益率变动数据]。

**[章节一主题]：**[核心结论] + [主要原因/数据支撑]。如有子要点，用（1）（2）展开。

**[章节二主题]：**[核心结论] + [数据或判断]。

**[策略/操作章节]：**[总体判断]。（1）[维度一，含品种+利差/收益率数据]；（2）[维度二]；（3）[维度三]。

[如有"下周关注"等前瞻事项，简短列举，置于风险提示前]。

风险提示：[原文]。
```

---

### 写法2：阶段分解型
适用于：季度复盘、年度复盘、阶段行情回顾等——报告以时间阶段划分为主结构。

先一句话概括整体表现（含关键收益率数据），再逐阶段概括（每阶段一句：时间范围 + 关键驱动因素 + 收益率变动幅度），最后一段提炼全期核心驱动因素。

```
[整体概括句：总时间跨度 + 整体表现定性 + 关键收益率变动数据，如"1y国债下行14BP至1.20%，10y下行4BP至1.81%"]。

根据[核心指标，如10y国债收益率]走势，[时间区间]可分为[N]个阶段：

**第一阶段（[时间范围]）：**[2-3句：核心驱动因素 + 市场表现 + 关键收益率变动数据]。

**第二阶段（[时间范围]）：**[同上]。

[后续阶段同格式]

**总结：**[1-2句概括全期核心驱动因素和市场运行的整体逻辑]。

风险提示：[原文]。
```

---

### 写法3：专题优先型
适用于：信用周报、有独立专题模块的策略报告等——报告前半段是专题深度分析，后半段是策略或跟踪数据。

专题部分详细展开（2-3段），策略/复盘部分精炼概括（1-2段），标准跟踪数据章节全部跳过。

```
**[专题主题]：**[专题核心结论，含关键数据]。[主体/品种间的分化情况，含具体数据]。[参与建议或结论]。

**[信用策略/市场复盘]：**[本周/近期整体表现概括，含数据]。

**[后市展望/操作建议]：**[总判断]。（1）[品种/期限维度一操作建议，含具体数据]；（2）[维度二]；（3）[维度三]。

风险提示：[原文]。
```

---

### 写法4：方法论型
适用于：量化研究报告、方法论创新报告——报告按"理论→方法→验证→系统"展开。

每章聚焦方法或步骤，保留技术名词（如"向前逐步回归法""Huber M-估计""凸优化"等），不做模糊化处理。有验证结论时引用核心数据。

```
**[背景/已有方法概述]：**（1）[方法A]：[特点和局限]。（2）[方法B]：[特点和局限]。

**[创新方法名称]——[核心思路]：**（1）[理论基础]。（2）[样本选取/数据处理]。（3）[步骤一]。（4）[步骤二]。（5）[验证结论，含关键误差数据]。

[如有第二种方法，同格式展开]

**[实践系统/应用成果]：**[系统覆盖维度和指标，简洁列举]。

风险提示：[原文]。
```

## 四、报告亮点撰写规范

**功能**：提炼本报告相较于一般性报告的差异化分析价值，突出研究贡献。

**共通格式要求**：
- 分**2～3个亮点**，每个亮点加粗标题，后跟2～4句说明。
- 亮点之间逻辑递进，通常从最核心的分析出发，到应用/结论层面。
- 不用空洞表述（"创新性地""深入研究"），改用具体描述（"通过跟踪XX数据""以XX为理论依据"）。
- 总字数：**150～280字**。

**根据第二步识别的属性，选择对应写法：**

---

**情形一：有方法论创新模块**

亮点 = 理论创新点 + 方法改进效果。需说明：① 以什么为理论依据；② 具体改进了什么；③ 改进后的效果（含数据）。通常2个方法亮点 + 1个实践落地亮点。

```
从[理论/实践]出发，从[角度A]和[角度B]两个维度提出[方法数量]种[研究对象]测算方法。
**（1）[方法A名称]：**以[理论依据]为基础，通过[改进手段]解决了[传统方法的缺陷]，[验证结论+数据]。
**（2）[方法B名称]：**从[数学公式/理论]出发，通过[处理方式]推算[研究对象]，通过与[对照方法]交叉验证确认可靠性。

**在实践落地方面，[系统/工具名称]：**[覆盖维度和指标，及其应用价值]。
```

---

**情形二：有专题分析模块（非方法论）**

亮点 = 专题分析的独特视角 + 核心结论的分析价值。需说明：① 分析了哪个细分领域；② 用什么数据或框架支撑；③ 得出了什么有指导意义的判断。通常1个专题亮点 + 1个策略框架亮点。

```
本期报告以[专题主题]为核心，从[角度A]和[角度B]两个维度进行分析。
**（1）[专题分析视角]：**通过梳理[具体数据，如财报数据、利差变化数据]，[识别出了什么现象/分化特征]，[判断的依据和参与建议]。
**（2）[策略配置视角]：**[从哪几个期限/品种维度构建了配置框架]，[各维度的核心逻辑和推荐方向]。
```

---

**情形三：无专题/方法论，为综合性策略报告（前瞻型）**

亮点 = 本期最独到的市场分析视角 + 数据支撑。需说明：① 在哪个维度做了区别于一般分析的深入观察；② 用什么数据或历史规律支撑；③ 对市场判断的意义。

```
本期报告围绕[核心主题]，从[角度A]和[角度B]两个维度进行分析。
**（1）[分析视角A]：**通过跟踪[具体数据指标]，[发现的规律或现象]，[对市场判断的指导意义]。
**（2）[分析视角B]：**[通过什么分析手段]，[区分的情形或历史阶段]，[当前属于哪种情形的判断]。

**在操作建议方面，**[从哪几个维度提供了具体参与框架，框架特点]。
```

---

**情形四：回顾型报告（复盘/阶段分析）**

亮点 = 分析框架的价值 + 对各阶段驱动因素的识别。需说明：① 采用了什么分析框架（如阶段分解）；② 识别出了哪些非显而易见的驱动因素；③ 分析结论对理解后续市场的意义。

```
本报告对[时间区间][市场]行情进行系统复盘，通过[N]阶段分析框架，梳理[整体特征，如"牛陡行情"]的形成逻辑。
**（1）[阶段分析的价值]：**通过识别[N]个关键阶段，分别揭示了[阶段1驱动]、[阶段2驱动]、[阶段3驱动]等不同市场主线的切换节点，为理解[市场结构特征]提供清晰框架。
**（2）[核心矛盾的识别]：**本期市场最关键的分歧在于[核心矛盾，如"通胀扰动 vs 资金宽松"]，报告从[具体数据/事件角度]梳理了[这一矛盾如何影响各期限表现]。
```

## 五、投资逻辑撰写规范

**功能**：从逻辑推演角度，阐述本报告核心判断的形成依据和操作方向。

**共通格式要求**：
- 分**两段**：第一段为分析依据/逻辑基础，第二段为操作建议或规律总结。
- 各段内部用**加粗的关键词 + 冒号**引出内容。
- 总字数：**150～280字**。

**根据第一步的时间视角，选择对应写法：**

---

**写法A：前瞻型报告**（有明确投资建议）

第一段 = 总体判断 + 支撑这一判断的2-3个核心逻辑（每条含简要数据支撑）。
第二段 = 按维度（品种/期限/利差/个券）列出具体操作建议，含数值或品种名称。

*适用于：利率周报、信用周报、月报、策略报告等。*

```
在[行情/信用]判断方面，[总体判断，如"短期震荡但利差压缩逻辑仍在"/"资管有钱仍是主线逻辑"]。**（1）[核心逻辑A]：**[依据+关键数据]。**（2）[核心逻辑B]：**[依据+判断]。**（3）[风险或观察点]：**[时间窗口+关注方向]。

在操作策略方面，[总体操作原则]。**（1）[维度一]：**[具体品种+利差/收益率数据+结论]；**（2）[维度二]：**[推荐方向+依据]；**（3）[维度三，如有]：**[具体操作要点]。
```

*若为方法论创新报告，第一段改为"问题→解决方案"逐条列举，第二段说明实践系统：*

```
在量化方法的改进与创新方面，针对传统方法的不足，提出针对性解决方案。**（1）[问题名称]：**[解决方案]；**（2）[问题名称]：**[解决方案]；**（3）[问题名称]：**[解决方案]；**（4）[问题名称]：**[解决方案]。

**在实践解决方案方面，[系统/工具名称]：**[系统的维度、指标及应用价值]。
```

---

**写法B：回顾型报告**（纯复盘，无操作建议）

第一段 = 全期核心驱动因素梳理：按阶段或逻辑链，列出各阶段的主导因素及其对收益率的影响方向。
第二段 = 规律总结：从本次复盘中提炼1-2条对理解市场有普适价值的规律或结论。

*适用于：季度复盘、年度复盘、阶段行情回顾等。*

```
在[时间区间]行情驱动方面，[N]个阶段的核心因素依次为：**（1）[阶段一时间范围]：**[主导因素+对收益率的影响，含BP数据]；**（2）[阶段二]：**[同格式]；**（3）[阶段三]：**[同格式]；**（4）[阶段四，如有]：**[同格式]。

从本期复盘提炼来看：**[规律一]：**[结论，如"配置盘进场时点通常在收益率上行至阶段高点附近，对利率上行形成保护"]；**[规律二]：**[结论，如"短端利率与政策工具的联动关系在本季表现为……"]。
```

## 七、写作原则

1. **忠于正文**：每句话必须有正文支撑，不得添加正文未提及的判断或数据。
2. **数据优先**：凡正文有具体数字（收益率点位、利差BP数、规模金额、时间节点）均优先引用，不用模糊描述替代。
3. **专业术语完整保留**：方法论类词汇（Huber估计、逐步回归、凸优化等）、市场类词汇（久期分歧度、骑乘收益率、换券、凸点等）、品种名称（二永债、摊余债基、城投债等）均需保留，不做泛化处理。
4. **标准跟踪章节一律跳过**：二级市场利差一览、一级市场发行净融资、成交流动性、评级调整等定期固定呈现的数据汇总章节，在摘要中不作概括。
5. **三个板块功能不重叠**：摘要是"是什么"（全文结构提炼），报告亮点是"为什么有价值"（分析贡献），投资逻辑是"怎么做/为什么这么做"（依据与操作）。同一句话不应出现在两个板块中。
6. **字数自律**：摘要不超过700字，报告亮点不超过280字，投资逻辑不超过280字。
7. **加粗规范**：加粗仅用于段落内子标题、关键方法/品种名称、核心结论句，不随意加粗描述性文字。
